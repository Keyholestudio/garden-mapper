# Garden Mapper — Decor Sticker Prompt Guide
_Last updated: 2026-06-09_

---

## 1. Base Prompt Template

All decor stickers use this base template. Fill in the variables per item.

```
Aerial side view. Art style: Plants vs. Zombies meets watercolor painting — tasteful simplified [ITEM NAME] with crisp edges, bold flat icon. Dark outline 2–3px. No shadows. Centered, 75% canvas fill. Vibrant and iconic.

Subject: [ITEM NAME]
Canvas: [SIZE]px square.
Colours: [COLOURS], flat chroma-key green background (#00FF00)
Shape: [SHAPE DESCRIPTION]
```

**Note:** Stairs use "Aerial side-front view" instead of "Aerial side view", and add `NO border. NO frame.` at the end of the Shape line.

## 4. Naming Convention

```
decor_{item-name}_{size-tier}_{regions}.png
```

Examples:
- `decor_rock-small_M_CA-US-FR-GB-AU.png`
- `decor_gazebo-oct_XL_CA-US-FR-GB-AU.png`
- `decor_stairs-wood_M_CA-US-FR-GB-AU.png`

All decor items use `family: 'Decor'` in `usePlantCatalog.js`. Water Feature items (fountains) use `family: 'Water Feature'`. Never use a plant family (Perennial, Shrub, etc.) for decor — it will cause the item to appear in the plant tray (see L022).
